GitSafe

Privacy

GitSafe is a GitHub repository backup tool.

Users connect their Google Drive through Google OAuth.

GitSafe uses the requested Google Drive permissions to store Git repository backups in the user's Drive.

GitSafe stores your GitHub access token and Google refresh token encrypted in its database so it can run backups you start and, if you turn on daily backups, back up your repositories once a day while you are signed out. Disconnecting an account or deleting your GitSafe account removes the stored tokens.

GitSafe uses a signed cookie to keep you signed in. It contains no OAuth tokens.

GitSafe does not sell user data.

Users can revoke Google's access to GitSafe through their Google Account.

GitSafe is currently a prototype/beta.
