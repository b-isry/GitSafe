How it works

From GitHub to your Drive: safely

Every backup is a complete, restorable snapshot. GitSafe builds it from your repository and stores it in your own Google Drive.

  • GitHub repository Your code, in the cloud
  • GitSafe Builds a complete snapshot
  • Google Drive Saved in your own Drive
  • .bundle backup One portable git bundle per repo
  • Download bundle Whenever you need it
  • Restore with Git Clone it back and keep working

Recovery

How do I restore my repository?

Each backup is a standard .bundle file. Drive backups are in the GitSafe folder of your Google Drive. A local backup is the same file, downloaded to the computer you are using. Git handles either one natively, so GitSafe isn't required to restore.

  1. 1

    Find the .bundle file in Google Drive

    Drive backups live in the GitSafe folder at the root of your Google Drive. A local backup is the .bundle file your browser downloaded. Find that file in your downloads folder.

  2. 2

    Clone the repository from the bundle

    The bundle contains your full history. Restore it into a new folder with git:

    $ git clone <your-bundle-file> <repository-folder>
  3. 3

    Keep working normally

    The restored folder is an ordinary git repository. Commit, push, and share it exactly as before.
